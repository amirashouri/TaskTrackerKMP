# 7.2 — Spring-based interpolation for glass intensity value

- **status:** done
- **priority:** P1
- **plan:** [`docs/PLAN.md`](../docs/PLAN.md) §7, entry `7.2`

## Scope

Modules: `shared-ui` (where `LocalGlassIntensity` is provided), `packages:design-system` (where `LocalGlassIntensity` is defined).
Layers: Shell/RootScreen composition boundary.
Cross-module change — requires ACK per `AGENTS.md` (touches 2+ Gradle modules).

## Files

- `shared-ui/src/commonMain/kotlin/com/tasktracker/sharedui/RootScreen.kt` — wrap the raw intensity in a spring animation using `animateFloatAsState` with `spring(dampingRatio = 0.8f, stiffness = Spring.StiffnessLow)`.
- `packages/design-system/src/commonMain/kotlin/com/tasktracker/designsystem/GlassIntensity.kt` — no change needed; `LocalGlassIntensity` remains the same.
- `shared-ui/src/commonMain/kotlin/com/tasktracker/sharedui/ShellPreferences.kt` — no change needed; exposes raw `StateFlow<Float>`.

## Contract

- [x] When `glassIntensity` changes (slider commit, settings restore, appearance change), the value provided to `LocalGlassIntensity` animates with a spring (not instant).
- [x] Spring spec: `dampingRatio = 0.8f`, `stiffness = Spring.StiffnessLow` — tuned for perceptual smoothness without overshoot.
- [x] The settled value exactly matches the target (no overshoot past target).
- [x] No pixel test changes needed — settled state is identical.
- [x] Manual verification: drag slider to 0%, release → observe spring settle to opaque; drag to 100%, release → observe spring settle to full glass.

## Validation

- Run: `scripts/check.sh full` (all three hosts)
- Manual: Run app, drag glass intensity slider, observe spring animation on commit.
- No baseline change expected (same test count).

## Handoff

- **Done:** Implementation complete in `RootScreen.kt`. All three hosts pass (JVM 2002, iOS 1948, Android 1644 tests). No test count change.
- **Pending:** None.

- **Gotchas:** The spring is at the composition boundary where `LocalGlassIntensity` is provided (via `ttTheme()`), not inside `ttGlassHairline()` — single source of truth for animated intensity. The spring only animates on *commit* (when `rawGlassIntensity` changes), not during preview drag — the preview already updates instantly via `onPreview` callback.
