## Contract

- [x] `ttGlass.GlassThickness` sealed class with three levels:
  - THIN: `baseAlpha = 0.45f` (chips, badges, inline elements)
  - STANDARD: `baseAlpha = 0.55f` (cards, segmented picker, flow picker slab) — default
  - THICK: `baseAlpha = 0.65f` (modal sheets, full-screen overlays)
- [x] `ttGlassSurface(shape, tint, thickness, borderWidth, base)` — new `thickness` parameter defaults to STANDARD.
- [x] `fillAlpha` parameter removed in favor of `thickness` (computed as `thickness.baseAlpha`).
- [x] All existing call sites updated with explicit thickness.
- [x] Pixel tests verify corrected transparency at STANDARD (0.55 base alpha).
- [x] Intensity scaling still works: at intensity 0, all thicknesses → opaque; at intensity 1, full thickness alpha.
