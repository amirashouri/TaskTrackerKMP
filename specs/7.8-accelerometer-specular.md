## Files

- `packages/design-system/src/commonMain/kotlin/com/tasktracker/designsystem/DeviceMotion.kt` (NEW) — `expect/actual` platform seam for device tilt (roll/pitch).
- `packages/design-system/src/androidMain/kotlin/com/tasktracker/designsystem/DeviceMotion.android.kt` — Android implementation using `SensorManager` + `TYPE_ROTATION_VECTOR`.
- `packages/design-system/src/iosMain/kotlin/com/tasktracker/designsystem/DeviceMotion.ios.kt` — iOS implementation using `CMMotionManager`.
- `packages/design-system/src/jvmMain/kotlin/com/tasktracker/designsystem/DeviceMotion.jvm.kt` — JVM stub (returns 0).
- `packages/design-system/src/commonMain/kotlin/com/tasktracker/designsystem/Glass.kt` — modify `ttGlassSurface` to read `LocalDeviceMotion.current.roll()` and offset specular highlight horizontally.

## Contract

- [x] `DeviceMotion` interface with `roll(): Float` (-1..1, left/right tilt) and `pitch(): Float` (-1..1, forward/back tilt).
- [x] Platform implementations:
  - Android: `SensorManager.getRotationMatrixFromVector` + `getOrientation` → roll/pitch in radians, normalized to -1..1.
  - iOS: `CMMotionManager.deviceMotion.attitude.roll/pitch` → normalized to -1..1.
  - JVM: Returns 0 (no motion).
- [x] `ttGlassSurface` reads `LocalDeviceMotion.current.roll()` and shifts specular highlight horizontally:
  - `specularOffset = roll * size.width * 0.15f`
  - Draw specular gradient from `(specularOffset, 0)` to `(specularOffset, SPECULAR_HEIGHT_DP)`
- [x] Clamp offset so highlight stays on surface.
- [x] Only applies when `base == null` (unbased glass fill).
- [x] No pixel test changes (dynamic effect, not static).
