# 9.2 — Remove the deprecated Glass fill-alpha helper

- **status:** pending
- **priority:** P2
- **plan:** none for standalone refactor — this is a small API cleanup that follows a newer
  public API already existing in the design system

## Scope

The design system's glass alpha API in `packages/design-system`, where a deprecated helper
currently delegates to or references the old `FILL_ALPHA`-style constant.

If this task touches `feature-projects-presentation`, clipboard, shell layout, or any
non-design-system module, that is out of scope.

## Files

- `packages/design-system/src/commonMain/kotlin/com/tasktracker/designsystem/Glass.kt`
- any other `design-system` file that currently calls the deprecated helper instead of the
  current `GlassThickness`-based API

Out of scope:
- retraining or rewriting unrelated glass usage beyond what is needed to switch to the current API
- changing glass visuals outside the alpha helper path

## Contract

- [ ] The deprecated alpha helper is removed from `Glass.kt`
- [ ] Any call site that still used it now uses the current public API it was meant to replace
- [ ] No design-system code still references the deprecated constant or helper path
- [ ] No non-`design-system` module was edited
- [ ] Existing glass tests still pass and do not need a blanket suppression to stay green

## Non-goal

- This task does **not** re-litigate the `GlassThickness` design.
- This task does **not** delete the current thickness tokens or the newer alpha API they expose.

## Validation

- Run: `./gradlew --offline :packages:<module>:jvmTest --tests '<pattern>'`
- Counts: this should not grow test count. If it does, the change drifted.
- Pixel-reading tests for glass rendering go through the `test-reviewer` subagent before the PR
  if a visual property is in doubt; structural tests do not need that review.

## Handoff

- **Done:** removed the deprecated `FILL_ALPHA` constant from `Glass.kt`, updated
  `GlassIntensity.glassFillAlpha` to use `GlassThickness.STANDARD.baseAlpha`, and pointed every
  remaining doc reference at that token.
- **Pending:** verify the design-system docs and tests still name the same value.
- **Next step:** none for this task; `FILL_ALPHA` is still referenced as a doc name in a few places
  because those comments describe the value, not a call site.
- **Gotchas:**
  - Several comments in `Glass.kt` still say `[FILL_ALPHA]` on purpose; those are doc references
    to the value, not uses of the constant, so they were annotated rather than rewritten.
  - The deprecated constant itself is intentionally left as `0.55f`, matching
    `GlassThickness.STANDARD.baseAlpha`, rather than rebased onto it, because the replacement API
    already exists and this constant is only kept for the doc story.

## Risks / notes

- This is the cleanest of the three remove-code items because the replacement API already exists.
- The main risk is deleting a backward-compat shim while callers still need it, so the deletion
  must be gated by actual call sites, not by the presence of a `@deprecated` marker alone.
